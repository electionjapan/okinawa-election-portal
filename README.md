# 沖縄選挙ポータル v0.9.32 — GitHubアップロード用

このフォルダは Streamlit Community Cloud 用の最小構成です。

## 更新方法
1. このフォルダの中身をすべて選択
2. GitHub の `electionjapan/okinawa-election-portal` で **Add file → Upload files**
3. 同名ファイルは上書きされます
4. Commit changes
5. Streamlit Community Cloud の再読み込みを待つ

## 反映確認
トップページ上部に **v0.9.23 · LIVE SHEET** と出れば新版です。
開票速報には **v0.9.23 · LIVE SHEET · NEW MAP** と表示されます。

## 地図について
アプリが読む表示用地図は `data/map_layout_v0912.geojson` だけです。
旧レイアウトGeoJSON(v0910以前)はこの配布物に含めていません。
ファイル名にバージョンを付けているのは、Streamlit Community Cloud側やブラウザ側の
キャッシュが古い地図を出し続けるのを防ぐためです。`st.cache_data` はv0.9.10で読込・整形処理に
再度付与しています(操作のたびにJSONを読み直さないようにするための高速化目的で、地図データ
自体はファイル名を変えるたびに必ず再取得されるため、古いキャッシュが表示され続ける心配はありません)。

## v0.9.31
- 「02A_投票速報入力」の読み取り不具合を修正。GVizのヘッダー自動推測が原因でタイトル行とヘッダー行がずれ、「列が見つからない」となっていたため、CSV取得URLに`&headers=0`を付けて自動推測を無効化。あわせて、列見出しの検出に失敗した場合の固定列インデックス(E列=当日有権者数_計、H列=投票者数_計)フォールバックを追加した。
- 各時刻を「全県実績」として採用する条件を厳格化。41市町村すべてに数値が入っていること、有権者数合計が既知の全県値(1,165,704人)から±2%以内であること、投票者数合計が0より大きいこと、をすべて満たした場合のみ採用するようにした。一部の市町村しか入力されていない状態では、その時刻を最新実績として扱わない。
- 読み取り診断パネルを拡張。時刻ごとに「読み込めた自治体数(例:41/41)」「有権者数合計」「投票者数合計」「算出投票率」「採用／未採用とその理由」を一覧表示するようにした。
- 最終速報が41市町村そろって確定した場合、ページの表示を「最終投票率予測」から「最終投票率」に切り替え、予測レンジ・点線予測系列を非表示にし、グラフの今回線を最終点まで実線で表示するようにした。
- `live_data.py`で、最終速報の投票者数に期日前投票者数を二重加算してしまう不具合を修正。中間速報(10:00〜19:30)の投票者数は当日票のみのため期日前票を合算するが、「最終」速報の投票者数はすでに最終投票者数そのもの(期日前含む)であるため、この場合は合算しないよう分岐した。
