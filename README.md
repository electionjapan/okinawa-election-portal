# 沖縄選挙ポータル v0.9.10 — GitHubアップロード用

このフォルダは Streamlit Community Cloud 用の最小構成です。

## 更新方法
1. このフォルダの中身をすべて選択
2. GitHub の `electionjapan/okinawa-election-portal` で **Add file → Upload files**
3. 同名ファイルは上書きされます
4. Commit changes
5. Streamlit Community Cloud の再読み込みを待つ

## 反映確認
トップページ上部に **v0.9.10 · NEW MAP** と出れば新版です。
開票速報・過去の選挙結果にも **v0.9.10 · NEW MAP · 模式配置** と表示されます。

## 地図について
アプリが読む表示用地図は `data/map_layout_v0910.geojson` だけです。
旧レイアウトGeoJSON(v098以前)はこの配布物に含めていません。
ファイル名にバージョンを付けているのは、Streamlit Community Cloud側やブラウザ側の
キャッシュが古い地図を出し続けるのを防ぐためです。`st.cache_data` はv0.9.10で読込・整形処理に
再度付与しています(操作のたびにJSONを読み直さないようにするための高速化目的で、地図データ
自体はファイル名を変えるたびに必ず再取得されるため、古いキャッシュが表示され続ける心配はありません)。


## v0.9.10
- トップへ戻るボタンがStreamlit標準ヘッダーの裏に隠れる問題を修正。標準ヘッダー自体を非表示にし、戻るボタン行を画面上部に固定表示(sticky)。
- 石垣市・与那国町の模式地図サイズを補正。与那国島が過大表示、石垣島が過小表示だったため、石垣島本体をさらに1.22倍拡大、与那国島本体を0.27倍に縮小し、実際の面積比に近い見た目へ調整。
- 地図をスマホで指ピンチ操作した際にズームできるよう、Plotlyチャートに`touch-action`のCSSを明示指定。
- 軽量化: 地図データの座標点数を30,670点→6,006点(約80%減)に削減。海面下の岩礁・干潟など目に見えない微小ポリゴンを間引き、残った海岸線もDouglas-Peucker法で簡略化。ファイルサイズは1.22MB→0.25MBに縮小。
- データ読込処理に`st.cache_data`を再付与し、スライダー操作などの再実行を高速化。
- 開票速報のシミュレーション方式は現状維持(本番の実入力機能への切替は別途対応予定)。
